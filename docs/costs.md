# PHASE 4 — Cost Analysis

Принцип: paid API не предполагается необходимым, пока не доказано обратное
(прямое требование раздела 27 задания). Ниже — честная раскладка, не
"продажа" платных сервисов.

## MVP cost (V1, единственный разработчик/исследователь)

| Статья | Стоимость | Комментарий |
|---|---|---|
| OpenDota API | **$0** | Бесплатно без ключа (60 req/min), бесплатно с ключом до 3000 req/day (`VERIFIED`, `docs/data-sources.md`) — MVP-объём (несколько тысяч про-матчей, не миллионы) укладывается в бесплатный тир на много запусков вперёд |
| `odota/dotaconstants` | **$0** | Статический open-source пакет |
| PostgreSQL | **$0** | Самостоятельный хостинг (тот же сервер, что API) или бесплатный тир управляемой БД (Supabase/Neon/Railway free tier — конкретный провайдер не выбирается в Phase 4, вне архитектурного скоупа) |
| Хостинг API + ingestion | **$0-5/мес** | Один небольшой VPS/контейнер достаточен для MVP-нагрузки (не production трафик, единичные запросы) |
| Object storage | **$0** | Не используется в MVP (ADR-002) |
| Compute для обучения | **$0** | CatBoost/sklearn на MVP-объёме данных обучаются за секунды-минуты на обычном CPU, GPU не нужен |
| SHAP | **$0** | Open source библиотека |
| **Итого MVP** | **≈ $0-5/мес** | Основное ограничение — не деньги, а сетевой доступ к источникам (см. `docs/environment-constraints.md`), не бюджет |

## Production cost (гипотетический, при реальной нагрузке пользователей)

| Статья | Оценка | Комментарий |
|---|---|---|
| OpenDota API с ключом | **$0, возможно единицы $/мес** | Если объём вырастет за бесплатный дневной лимит (3000/день) — биллинг $0.01/100 вызовов (`VERIFIED`) — даже при 10 000 запросов/день сверх лимита это доли доллара в день |
| STRATZ Individual token (fallback) | **$0** формально, но требует реферальной квоты (1000/мес) | Нецелесообразно для проекта без собственной пользовательской базы — см. `docs/data-sources.md`, Категория 4 |
| Liquipedia API | **$0** | Бесплатно, только rate-limited (`docs/data-sources.md`) |
| PostgreSQL (управляемый, продакшн-тир) | **$10-25/мес** | Managed instance с бэкапами, при росте объёма данных |
| Хостинг API (масштабируемый) | **$5-20/мес** | Один-два инстанса, без Kubernetes |
| Object storage (при миграции с JSONB, ADR-002) | **$1-5/мес** | Только если объём raw-данных вырастет значительно (например, переход на public matches, вне текущего скоупа) |
| Мониторинг (если появится необходимость сверх structured logging) | **$0-10/мес** | Бесплатные тиры Grafana Cloud/подобных — не требуется на MVP (раздел 9 `docs/architecture.md`) |
| **Итого production (умеренная нагрузка)** | **≈ $20-60/мес** | Всё ещё далеко от "требует серьёзного бюджета" |

## Optional paid services (явно НЕ необходимы, но могут ускорить работу)

| Сервис | Что даёт | Почему опционально |
|---|---|---|
| STRATZ Multi-token | Практически неограниченный доступ к альтернативному источнику | Нужно только при реальной недоступности OpenDota, не для MVP |
| Esports Charts полный доступ | Зрительская статистика как доп. признак важности турнира | Признак с низкой ожидаемой ценностью (`docs/features.md`, категория G) — не обосновано тратить деньги без доказанной пользы для метрик |
| Managed MLflow / experiment tracking SaaS | Более удобный UI для сравнения экспериментов | ADR-004: `models` таблица в Postgres достаточна для MVP; подключить позже, если/когда объём экспериментов оправдает |
| GPU-инстансы для обучения | Ускорение обучения | Не нужно — CatBoost/sklearn на этом объёме данных не упираются в CPU |

## Вывод

На всём горизонте, спроектированном в Phase 4 (V1-V4), проект остаётся
финансируемым из кармана исследователя (единицы-десятки долларов в месяц
максимум). Единственная статья, которая может стать нетривиальной —
managed PostgreSQL при значительном росте объёма данных, что само по себе
хороший сигнал ("проект действительно используется"), не архитектурный
просчёт.
