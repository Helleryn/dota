## 2. Главная находка аудита

> **Из пяти замороженных признаков до драфта существуют не все.**

| Признак | Требует | Доступен pre-match? |
|---|---|---|
| `elo_difference` | только id команд | **да** |
| `form_3_difference` | только id команд | **да** |
| `elo_mean_diff` | **состав** | только если состав известен |
| `five_vs_team_elo_diff` | **состав** | только если состав известен |
| `hero_exp_decay_diff` | **выбранных героев** | **нет** — драфта ещё не было |

`hero_exp_decay_diff` считается как средняя сила героев из
`radiant_picks` / `dire_picks`, то есть из **фактического драфта**. До
начала драфта этих героев не существует физически. Подставить туда
что-либо — значит выдумать данные.

Phase 15 этого не заметила, потому что replay брал признаки из кэша,
посчитанного по уже сыгранным матчам. Формально утечки там не было
(признаки prefix-safe), но **режим не был pre-match**: он был
«post-draft, до исхода».

### Следствие: три уровня доступности

```
T0 FULL              5 признаков   — то, что оценивали Phase 14/15
T1 PRE_DRAFT+ROSTER  4 признака    — драфта нет, состав известен
T2 PRE_DRAFT−ROSTER  2 признака    — ни драфта, ни состава
```

Phase 16 замерила, что полный состав известен лишь у **10.1%**
предстоящих матчей, а за сутки до старта — у **5.5%**. То есть в
реальном продукте **преобладает уровень T2**.

## 3. Вторая находка: горизонт прогноза — измеримая величина

Замер по 109 754 матчам: хотя бы одна из двух команд играет

| Окно до старта | Доля матчей |
|---|---:|
| 1 час | **32.3%** |
| 3 часа | 64.7% |
| **24 часа** | **85.0%** |
| 7 суток | 96.7% |

Значит `elo_difference` и `form_3_difference` на T−24ч и на момент
старта — **разные значения у 85% матчей**. Прошлые фазы этого не
измеряли: признаки всегда считались на момент старта.

### L10 — дефект, найденный при построении PIT-движка

Первая версия загрузчика брала одно и то же множество матчей и для
обновления состояния, и для выдачи признаков. Замороженный конвейер так
не делает: он обновляет team-Elo и форму по **всем** pro-матчам, а
признаки выдаёт только для подмножества с полным драфтом и десятью
игроками.

Расхождение: **team-Elo в среднем на 2.1, максимум на 48.3**. Формула
была верной, популяция — нет. После исправления расхождение упало до
машинной точности (5.7e-14).

Это ровно тот класс дефекта, который не виден без сверки с эталоном:
цифры выглядели правдоподобно.
