# PHASE 17 — prospective режим: исторический replay и живой shadow

## 1. Исторический prospective replay

Для каждого исторического матча `prediction_at = start − horizon`, и
система ведёт себя так, будто матч ещё не сыгран.

Проверено по каждому пункту требований PART M:

| Что | Как обеспечено | Тест |
|---|---|---|
| ростер на T | `RosterProvider`, пусто если неизвестно | `test_unknown_roster_yields_none_not_defaults` |
| статистика героев только до T | затухание по матчам < T | `test_future_draft_actions_do_not_change_features` |
| player-Elo только до T | событие UPDATE после PREDICT | `test_future_result_does_not_change_earlier_features` |
| team Elo только до T | то же | `test_match_between_prediction_time_and_start_is_invisible` |
| форма только до T | то же | там же |
| калибровка из разрешённой истории | Phase 14, скользящее окно по прошлому | Phase 14 tests |
| драфт только до T | PRE_DRAFT не использует драфт | `test_pre_draft_mode_does_not_compute_hero_feature` |
| нет today's-state | провайдер по `match_id`, без «последнего известного» | `test_todays_roster_is_not_used_for_yesterday` |

## 2. Живой shadow на настоящих будущих матчах

`scripts/phase17_live_shadow.py` соединяет три готовых куска: обнаружение
Phase 16, признаки Phase 17, неизменяемый снимок Phase 15.

Результат запуска 2026-08-26:

```
источник: Valve DPC (официальный, ключ не нужен)
будущих матчей: 38   запас по времени: 3 … 457 часов

READY              0
UNKNOWN_TEAMS     38
LOW_HISTORY        0

сохранено снимков: 38
```

**Ни одного пригодного прогноза, и это правильное поведение.**

### Причина, названная прямо

Все 20 команд этих матчей **отсутствуют в нашей базе**. Лига 19081,
дающая 38 из 38 будущих матчей, вообще не значится в нашей таблице лиг:
она не относится к `professional`/`premium`, а именно этим фильтром
ограничен весь датасет проекта.

Это **несовпадение охвата**, а не сбой:

| Что можно было заподозрить | Проверено |
|---|---|
| API не работает | работает, 200, 38 матчей |
| идентификаторы не сопоставляются | сопоставляются: `team_id` у Valve и у нас — одно пространство |
| база устарела | свежайший матч 2026-08-24, разрыв двое суток |
| **лига вне домена модели** | **да: лиги 19081 нет в нашей таблице лиг** |

Для сравнения: The International 2026 (лига 19719) в базе есть, tier
`premium`, 147 матчей — но будущих матчей у неё нет, турнир завершён.

### Что система сделала правильно

* распознала, что истории команд нет (`played = 0`);
* выставила статус `UNKNOWN_TEAMS` и решение `ABSTAIN`;
* **не выдала 50%** как «прогноз»;
* сохранила 38 неизменяемых снимков с полным набором меток среза.

Прогноз «0.500 при нулевой истории» формально вычислим — Elo обеих
команд равен базе. Именно поэтому проверка на историю стоит **до**
вычисления вероятности: иначе система выдавала бы уверенное на вид число
там, где не знает ничего.
