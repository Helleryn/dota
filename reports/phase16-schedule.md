## 1. Valve DPC — официальный, бесплатный, но разреженный

Структура: `GetLeagueData?league_id=` → `node_groups` → вложенные
`node_groups` → `nodes`. Узел содержит:

```
node_id, scheduled_time, team_id_1, team_id_2, series_id,
has_started, is_completed, matches, stream_ids,
incoming_node_id_1/2, winning_node_id, losing_node_id
```

Скан **106 активных лиг** (активность за 30 дней):

| Величина | Значение |
|---|---:|
| узлов всего | 1 142 |
| с заполненным `scheduled_time` | **219 (19.2%)** |
| **будущих матчей** | **38** |
| лиг, содержащих будущие матчи | **1 из 106** |
| `registered_players` суммарно | **0** |
| будущих узлов с готовыми `match_id` | 0 |

Запас по времени у этих 38 матчей:

| Порог | Матчей |
|---|---:|
| ≥ 1 ч | 38 |
| ≥ 24 ч | 36 |
| ≥ 72 ч | 32 |
| ≥ 7 суток | 24 |
| ≥ 14 суток | 12 |

медиана **219.5 ч (≈9 суток)**, максимум 460 ч.

**Оценка честная: источник официальный и точный, но заполнение сетки
зависит от организатора.** 38 будущих матчей из одной лиги — это не
покрытие сцены, это одна хорошо оформленная лига. Как единственный
источник непригоден.

## 3. Ловушка пагинации, которую стоит записать

Параметры `offset`/`limit` bo3.gg **молча игнорирует** и возвращает
первые 10 записей без ошибки. Работают только `page[offset]` и
`page[limit]`.

Неверный параметр здесь не даёт сбоя — он даёт **неполные данные**.
Ровно тот же класс дефекта, что Phase 15 нашла у себя дважды (аудит
проверял 10 000 из 14 969, разрешение закрывало 5 000 из 14 944).
Проверка, молча работающая на части данных, опаснее отсутствующей.

## 4. Вывод по расписанию

| Роль | Источник | Основание |
|---|---|---|
| **PRIMARY** | **bo3.gg** | 378 матчей, 82% известны за сутки |
| **SECONDARY** | **Valve DPC** | официальная точность, `team_id` Valve напрямую |
| BACKUP | опрос `/live` OpenDota | ловит матч в драфте, покрытие случайное |
| REJECTED | Steam Web API | `GetScheduledLeagueGames` — 404 |

Valve стоит вторым не по качеству, а по покрытию: там, где он есть, он
лучше (официальные `team_id` без сопоставления идентичностей), но есть
он редко.
